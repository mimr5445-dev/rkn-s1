# Project context

- **Name:** rkn-s1 (README title: aiTrends 2D Studio), version 0.1.0.
- **What it is:** a Claude Plugin. It turns a voiceover into a stick-figure video, rendering each frame with
  code (HTML Canvas and Three.js) and not with generative image or video models.
- **Layout:** `skills/make-2d-video/` is the core (SKILL.md, `kit/` engine, audio, tools, examples, references).
  The other four skills are command wrappers around it.
- **Single branch:** `main`. Nothing is merged to `main` without the owner's explicit approval.
- **Open governance questions:** license (undecided), and the source of truth for `verify_kit.py` hashes.
